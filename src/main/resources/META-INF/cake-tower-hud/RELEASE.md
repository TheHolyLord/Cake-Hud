# Cake Tower HUD 2.0.2

Cake Tower HUD 为《蛋糕塔》第三章（Cake Team Towers Chapter 3）制作。HUD 指游玩时叠在画面上的信息面板。这个模组把自己的状态、队友血量、角色属性和战斗数据集中在画面上，爬塔时可以一眼查看。

## 功能

- **自己的状态**：在快捷栏上方查看血量、碎心、魔力、金币、命数，以及地图为当前职业提供的其他状态。
- **队友和敌人**：在队友列表查看头像、名字、血量与命数，也能查看离自己较近的队友和敌人的头顶血条。敌人可显示护甲、抗性和额外心，各项可单独关闭。
- **角色属性**：可选择在背包内或游戏画面上显示，支持拖动位置、左右对齐、调列数和隐藏指定属性。背包左侧的关键词说明可按 `Alt` 固定或关闭。
- **战斗统计**：按 `N` 查看总表和分关表，包括伤害、承伤、击杀、助攻和用时。DPS 指每秒伤害。仅装客户端时，可统计客户端看得到的伤害粒子，结果为全场聚合。有服务端数据时可以查看玩家各自的记录。战斗统计为实验性功能，战绩广播默认关闭。
- **其他提示**：盾牌冷却可选横向长条或竖向指示器。持弓时可显示下一支箭。游戏中央的标题和副标题可分别改位置、大小及透明度。

## 安装与使用

1. 适用于 Minecraft `26.3`、Java `25` 和 Fabric。Fabric 是给游戏装模组的底座。把 `cake-tower-hud-2.0.2.jar` 和适用于 `26.3` 的 Fabric API 一起放入 `mods` 文件夹，升级时先移出旧版。
2. 进游戏按 `F8` 打开设置。可以调整两个面板的位置、头顶血条长度，也可以切换数字简写和各项提示。`H` 切换自定义血条，`J` 切换背包外的属性面板，`K` 切换 Boss 栏显示，`N` 打开战斗统计表。这些键可在游戏的控制设置里修改。
3. 自己安装就可以使用客户端功能。服务器可选装同一份模组以同步敌人血量、玩家属性、队友各类心与碎心以及 NPC 标记。服务器未安装时，显示内容取决于地图发给客户端的数据。

完整变更见 [更新日志](CHANGELOG.md)。部分设置方式参考了 [Cake-Hud-Lite](https://github.com/nyaLium/Cake-Hud-Lite)。
